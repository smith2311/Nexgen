{% comment %} Icon picker for the Capability Master. The form's `icon` is a HiddenInput; this is what sets it. A trigger button shows the icon currently chosen, and opens a drawer of the curated 3PL palette from constants.CAPABILITY_ICON_GROUPS — grouped by what a capability actually is (certification, storage, cold chain, transport, customs, systems, handling, service) and filterable by typing. Only a palette icon can be picked, so a class Font Awesome cannot render — which shows on every screen as a blank square — is not reachable from the UI. The form enforces the same thing server-side; this is the half that makes it usable. Needs in context: `form` (with an `icon` field) and `icon_groups`.
