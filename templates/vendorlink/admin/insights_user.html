Charts are Highcharts (vendored); the heatmap is a CSS grid — see _heatmap.html for why. Every series is built in vendorlink/useractivity.py. Five views of the same data, each answering something the others cannot: * Daily trend, stacked by work type, with this person's own average as a dashed plotLine and a cumulative spline on a second axis — the last is what turns "busy days" into "are they still active". * Personal heatmap — their own shift shape. * Work mix donut + per-activity bar — WHAT they did. * Weekday pattern — averaged per occurrence, not summed. * Event feed — the actual sequence, newest first. Plus a Standing panel: rank, team median and a signed delta.
