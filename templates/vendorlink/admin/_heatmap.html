{% comment %} Weekday x hour activity heatmap. Shared by insights.html and insights_user.html. Expects `heat` from useractivity.heatmap(): `rows` (7 weekdays, each with 24 cells carrying a 0-5 `level`), `hours`, `levels`, `peak`, `total` and `busiest`. Why this is CSS and not Highcharts: the vendored Highcharts 12.1.2 bundle registers only area/areaspline/bar/column/line/pie/scatter/spline — no heatmap module and no colour axis — so a heatmap series would draw an empty frame. A 7x24 CSS grid is a real heatmap, adds no dependency, and themes from vl-insights.css. Why weekday x hour rather than a calendar: this is the cell that earns a heatmap. A daily trend collapses the hour axis and an hourly histogram collapses the weekday axis, so neither can show "Monday mornings heavy, Friday afternoons dead" — the pattern only exists in two dimensions. Caller sets `heat_title` and `heat_note`. {% endcomment %}
