{% extends "merilv/_base.html" %} {% load static merilv_ui %} {% comment %} Reports → User Activity → one user. Admin-only individual tracking. Charts are Highcharts (see reports_users.html for the why). Every series is built in merilv/useractivity.py; this template only places containers. Six views of the same data, each answering something the others cannot: * Daily trend, stacked by work type, with the user's own average as a dashed plotLine and a cumulative line on a second axis — the last is what turns "busy days" into "are they still working". * Active window per day — the "how much time" trend. * Hour-of-day — the shift pattern, in Asia/Kolkata. * Weekday — averaged per occurrence, not summed. * Work mix donut + per-source bar — WHAT they did. * Event feed — the actual sequence. Plus a peer-standing panel: rank, team median, and a signed delta. Performance only means something relative, and an admin should not have to eyeball whether 4,000 scans is a lot. Honesty caveat, same as the roster: "Active window" is an engagement span, not attendance.
