{% icon "info" %} How to read this

Actions
Every row this person created across all 15 tracked tables — scans, sessions, uploads, closures and master-data edits. Not just the activity log, which only covers admin edits.
Active window
First to last action each day, summed. An engagement span, not a timesheet — breaks inside a day are counted. No login/logout tracking exists in this module.
Session time
Real open-to-last-write duration of console sessions. Narrower but truer; an upload or a master-data edit has no duration at all.
Idle accounts
Hold a Meril-V role but logged nothing in this window.
