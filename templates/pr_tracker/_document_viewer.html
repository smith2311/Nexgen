{% comment %} The document preview overlay. Include once per page. Two callers, wanting different things: * the PR screens preview a document that is already stored — it has a URL on the server and a download worth offering; * the Assign form previews a file the browser is still holding, chosen a moment ago and not uploaded yet. There is no server URL, and a download button would offer someone the file they just picked off their own disk. So the overlay exposes window.prtDocViewer.open() and the two callers pass what they have. The `.js-doc-preview` wiring below is just the first caller's adapter over that same call. {% endcomment %}
