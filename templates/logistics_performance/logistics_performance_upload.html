⚡ EDD Calculation Logic

  • TAT is fetched from Location Master using Courier Code + Mode
  • EDD = Dispatch Date + TAT days
  • Sundays between dispatch and EDD are skipped (+1 day per Sunday)
  • If TAT not found → EDD = null (updated automatically when TAT is added to Location Master)

📋 Upload Notes

  • Max file size: 10 MB
  • First row must be column headers
  • Duplicate docket numbers flagged
  • Review preview before confirming
  • Error rows are skipped on import
