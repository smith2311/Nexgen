Expected Excel Format

  • Row 1: Building names, one per floor-column group — e.g. Meril Park 3 merged across its 4 floor columns, then Meril Park and Academy each over their own single floor column. A file with only one building can leave row 1 blank except an optional title in cell A1.
  • Row 2: Headers — Condition | Check list | [any columns before the email column are ignored] | Internal department Email ID | [one column per floor, named after that floor]
  • Row 3+: Data — condition name only in the first row of each group; checkpoint text in every row
  • Every floor column after Internal department Email ID holds that floor's responsible email directly: a filled cell means the checkpoint applies to that floor with that owner, a blank cell means it doesn't apply. Buildings, floors, conditions and checkpoints are all created/updated automatically — no manual building name needed.
